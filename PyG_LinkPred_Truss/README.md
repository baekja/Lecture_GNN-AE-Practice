# 링크 예측 예제 — 트러스의 누락 부재 찾기

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/baekja/Lecture_GNN-AE-Practice/blob/main/PyG_LinkPred_Truss/truss_linkpred_example.ipynb)

건설빅데이터분석 · 그래프 신경망 **W09 링크 예측** 강의노트의 예제 노트북입니다.
트러스를 그래프(절점 = 노드, 부재 = 엣지)로 보고, 도면에서 **빠진 부재를 링크 예측으로 찾은 뒤**, 찾은 부재로 복원한 트러스를 **직접강성법으로 해석**해 검증합니다.

- **데이터**: 직접 생성한 평행현 트러스 60동(Pratt · Howe, 패널 4–8). 학습 40동은 완전한 도면, 시험 20동은 부재 20%를 가림
- **방법**(강의노트의 방법을 모두 다룸)
  - 휴리스틱: 공통 이웃 · Jaccard · Adamic–Adar · Katz(β = 0.1, β < 1/λmax 확인) · 거리 · 차수 결손
  - GAE · VGAE: 2층 GCN 인코더 + 내적 디코더, 완전한 트러스에서 부재를 가려 가며 학습(귀납)
  - GNN + MLP 디코더: 두 절점 임베딩 + 좌표 차, 학습 음성의 절반을 가까운 비부재로
  - SEAL 간이판: 1홉 부분그래프 + DRNL 원-핫 + GCN 3층 · 평균/최대 풀링(교재 DGCNN의 정렬 풀링 대신)
- **채점**: AUC · AP · Hits@10(무작위 음성), 대각재 방향 승률(같은 패널의 반대 대각선과 대결), 트러스 완전 복원 수(직접강성법으로 안정 여부와 처짐 확인), 시드 3개 평균 ± 표준편차
- **실행**: CPU만으로 충분합니다. 노트북 전체 Colab 실측 약 87초(기본 CPU 런타임)

**배울 점** — 무작위 음성 AUC가 높아도(GAE 0.941) 가까운 후보 가운데서 고르는 실제 복원은 실패할 수 있습니다. 지표만 보지 말고 구조해석으로 검증합니다. 대칭인 두 대각선은 거리 · 공통 이웃으로 가를 수 없고, Adamic–Adar · Katz는 오히려 반대쪽을 고릅니다. 음성을 어떻게 뽑고 모델이 무엇을 보느냐가 모델이 배우는 것을 정합니다.

## 예제 2 — 링크 가중치 예측: 트러스 부재의 강성 찾기

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/baekja/Lecture_GNN-AE-Practice/blob/main/PyG_LinkPred_Truss/truss_linkweight_example.ipynb)

예제 1의 "부재가 있는가"(0/1)를 "부재가 얼마나 센가"(강성)로 넓힌 **링크 가중치 예측(엣지 회귀)** 예제입니다. 강성 0을 '부재 없음'으로 두면 두 문제가 하나로 합쳐집니다.

- **데이터**
  - 예제 1과 같은 트러스 60동(같은 시드)에 손상을 줍니다: 트러스마다 부재 1–3개, 강성비 s = EA/EA₀ = 0.3–0.8
  - 모든 절점에 무작위 하중 3개를 걸고, 직접강성법으로 계측 변위를 만듭니다
  - 검증에는 학습에 쓰지 않은 표준 하중(아래현 절점마다 10 kN)을 씁니다
- **식별 가능성**: 흔한 재하 시험 3종에서는 부재의 9.6%가 힘을 받지 않아 강성을 알 수 없습니다. 무작위 절점 하중에서는 0%입니다
- **방법**
  - 고전 역해석
    - 평형식 최소제곱: 모든 절점을 계측하면 평형식이 강성에 대해 선형입니다
    - 트러스별 역해석: 미분 가능한 직접강성법으로 강성을 경사하강합니다
  - GNN: 예제 1과 같은 2층 GCN 인코더 + 엣지 회귀 헤드
    - 입력: 하중 · 변위 · 겉보기 부재력(변형률) · 's = 1 가정 절점 평형 잔차'
  - 손실 세 가지
    - 지도학습형: 강성 라벨의 MSE
    - 물리결합형: 예측 강성으로 직접강성법을 풀어 계측 변위와 비교합니다. 라벨이 필요 없습니다
    - 혼합: 둘의 합
  - 존재 + 강성: 예제 1과 같은 가린 부재 95개에서, 후보 쌍마다 강성을 예측합니다(비부재 = 0)
- **실행**: CPU만으로 충분합니다. 노트북 전체 약 30초입니다. Colab과 같은 버전 조합의 새 가상환경에서 오류 없이 실행했고, 실제 Colab 화면 확인은 아직입니다

### 실행 결과 (노트북에 저장된 출력, 시드 0 · 1 · 2 평균)

강성 찾기 — 부재가 모두 보일 때

| GNN 지도학습형 (평형 잔차 피처 없음) | 0.753 | 0.419 | 2.154 |
| GNN 물리결합형 (평형 잔차 피처 없음) | 0.720 | 0.450 | 0.101 |

**배울 점**
- 계측이 충분하면 물리(평형식)만으로 정확히 풀립니다.
- 지도학습형은 손상 위치를 잘 찾습니다. 하지만 그 강성으로 새 하중을 해석하면 '손상 없음 가정'보다 처짐이 더 틀립니다.
- 강성 라벨 없이 배우는 물리결합형만 기준선 수준을 지켰습니다. 지표가 좋아도 구조해석으로 검증합니다.
- 거동 정보(하중 · 변위)를 더하면, 예제 1에서 형상만으로는 가르지 못하던 대칭 대각선을 가릅니다.
