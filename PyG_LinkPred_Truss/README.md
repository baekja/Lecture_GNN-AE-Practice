# 링크 예측 예제 — 트러스의 누락 부재 찾기

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/baekja/Lecture_GNN-AE-Practice/blob/main/PyG_LinkPred_Truss/truss_linkpred_example.ipynb)

건설빅데이터분석 · 그래프 신경망 **W09 링크 예측** 강의노트의 예제 노트북입니다.
트러스를 그래프(절점 = 노드, 부재 = 엣지)로 보고, 도면에서 **빠진 부재를 링크 예측으로 찾은 뒤**, 찾은 부재로 복원한 트러스를 **직접강성법으로 해석**해 검증합니다.

- **데이터**: 직접 생성한 평행현 트러스 60동(Pratt · Howe, 패널 4–8). 학습 40동은 완전한 도면, 시험 20동은 부재 20%를 가림
- **방법**(강의노트의 방법을 모두 다룸)
  - 휴리스틱: 공통 이웃 · Jaccard · Adamic–Adar · Katz(β = 0.1, β < 1/λmax 확인) · 거리 · 차수 결손
  - GAE · VGAE: 2층 GCN 인코더 + 내적 디코더, 완전한 트러스에서 부재를 가려 가며 학습(귀납)
  - GNN + MLP 디코더: 두 절점 임베딩 + 좌표 차, 학습 음성의 절반을 가까운 비부재로
  - SEAL 간이판: 1홉 부분그래프 + DRNL 원-핫 + GCN 3층 · 평균/최대 풀링(교재 DGCNN의 정렬 풀링 대신)
- **채점**: AUC · AP · Hits@10(무작위 음성), 대각재 방향 승률(같은 패널의 반대 대각선과 대결), 트러스 완전 복원 수(직접강성법으로 안정 여부와 처짐 확인), 시드 3개 평균 ± 표준편차
- **실행**: CPU만으로 충분합니다. 노트북 전체 약 70초(아래 검증 환경 기준)

**배울 점** — 무작위 음성 AUC가 높아도(GAE 0.941) 가까운 후보 가운데서 고르는 실제 복원은 실패할 수 있습니다. 지표만 보지 말고 구조해석으로 검증합니다. 대칭인 두 대각선은 거리 · 공통 이웃으로 가를 수 없고, Adamic–Adar · Katz는 오히려 반대쪽을 고릅니다. 음성을 어떻게 뽑고 모델이 무엇을 보느냐가 모델이 배우는 것을 정합니다.
