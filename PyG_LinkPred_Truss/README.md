# 링크 예측 예제 — 트러스의 누락 부재 찾기

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/baekja/Lecture_GNN-AE-Practice/blob/main/PyG_LinkPred_Truss/truss_linkpred_example.ipynb)

건설빅데이터분석 · 그래프 신경망 **W09 링크 예측** 강의노트의 예제 노트북입니다.
트러스를 그래프(절점 = 노드, 부재 = 엣지)로 보고, 도면에서 **빠진 부재를 링크 예측으로 찾은 뒤**, 찾은 부재로 복원한 트러스를 **직접강성법으로 해석**해 검증합니다.

- **데이터**: 직접 생성한 평행현 트러스 60동(Pratt · Howe, 패널 4–8). 학습 40동은 완전한 도면, 시험 20동은 부재 20%를 가림
- **방법**: 공통 이웃 · Adamic–Adar · 거리 · 차수 결손(휴리스틱), GAE(강의노트의 2층 GCN + 내적 디코더), GNN + MLP 디코더(좌표 차 · 어려운 음성)
- **채점**: AUC · AP(무작위 음성), 대각재 방향 승률(같은 패널의 반대 대각선과 대결), 트러스 완전 복원 수(직접강성법으로 안정 여부와 처짐 확인)
- **실행**: CPU만으로 충분합니다. 로컬 CPU(Python 3.11 · torch 2.9.1 · PyG 2.7.0)에서 노트북 전체 약 20초

## 실행 결과 (노트북에 저장된 출력)

시험 트러스 20동 · 가린 부재 95개 · seed 0

| 방법 | AUC (무작위 음성) | 대각재 방향 승률 | 완전 복원 |
|---|:-:|:-:|:-:|
| 거리 (가까울수록 높게) | 0.985 | 0.500 | 8/20 |
| 차수 결손 | 0.646 | 0.675 | 2/20 |
| GAE (내적 디코더) | 0.941 | 0.650 | 0/20 |
| GNN + MLP 디코더 (어려운 음성 섞음) | 0.995 | 0.650 | 8/20 |

시드 0 · 1 · 2의 평균 ± 표준편차
- 완전 복원 비율: GNN + MLP 디코더 0.467 ± 0.115 · 거리 0.267 ± 0.126 · GAE 0.000 ± 0.000
- 대각재 방향 승률: GNN + MLP 디코더 0.802 ± 0.131 · 차수 결손 0.769 ± 0.085 · GAE 0.761 ± 0.099 · 거리 0.500 ± 0.000

**배울 점** — 무작위 음성 AUC가 높아도(GAE 0.941) 가까운 후보 가운데서 고르는 실제 복원은 실패할 수 있습니다. 지표만 보지 말고 구조해석으로 검증합니다. 음성을 어떻게 뽑고 디코더가 무엇을 보느냐가 모델이 배우는 것을 정합니다.
